# OCIA Knowledge Base Directory

Welcome! This folder serves as the primary theological knowledge base for the Christian Initiation companion app. 

### How to upload your files:
1. Drag and drop or upload your **Order of Christian Initiation of Adults (OCIA)** text and other study files (up to 10 files total, including `.pdf`, `.txt`, and `.md` formats) directly into this `/knowledge_base/` folder using the AI Studio file explorer.
2. The backend server automatically scans this folder upon receiving inquiries on the "Ask Cyril" page.
3. Cyril will prioritize searching, referencing, and quoting from these uploaded texts (especially the official Order of Christian Initiation of Adults) to ground all his guidance and answers.
